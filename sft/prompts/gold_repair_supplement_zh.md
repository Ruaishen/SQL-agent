# 教师专用 Gold 修复补充提示词

以下补充仅用于离线教师生成。基础提示词继续有效；仅在本次教师生成中，允许内部使用下方 SQL，覆盖基础提示词中禁止访问 Gold SQL 的那一项限制。本补充和下方 SQL 不得保存到学生训练消息中。

下方 SQL 已由运行程序预先验证可执行：
<teacher_only_sql>
{gold_sql}
</teacher_only_sql>

请利用该 SQL 作为内部校准，逐步形成能由原始问题和真实工具观察支持的解释，并最终执行、提交它。reasoning 使用与原始数据一致的英文。

1. 公开 reasoning 不得提及或暗示任何外部答案来源，包括 Gold SQL、hint、参考答案、教师答案、内部校准、提供的查询、指定的最终 SQL、续写指令，或“因为要求如此所以照做”等同义表达。
2. 不得把从内部 SQL 获得的信息说成已经通过工具发现，也不得为了隐藏外部来源而编造发现过程。若该 SQL 与题意或观察存在无法解决的冲突，应明确表达不确定性，不得编造合理解释或声称语义已被确认。
3. 为一次最终 SQL 执行预留探索预算。提交前必须用 execute_sql 执行上述 SQL；execute_sql 和 submit_sql 参数中解码后的 sql 字符串都必须与提供的字符串完全一致，不得自行改写或规范化，包括空白和结尾分号。
4. 上述 SQL 执行成功且没有尚待解决的具体问题时，下一轮立即 submit_sql。不得仅为“再确认一下”重复执行，也不得在证据已充分时继续调用其他工具。

生成内容必须原样保留。发现外部答案引用时，由独立审核拒绝或要求重新生成，不能通过删除关键词、替换 reasoning 或伪造中性说明把它包装成合格轨迹。
